# 🎌 LPKS Arima Persada - Landing Page Website

Website *landing page* modern, responsif, dan interaktif untuk **LPKS Arima Persada** (PT. Arima Bangkit Persada). Proyek ini dirancang untuk mempromosikan program pelatihan kerja dan persiapan karir ke Jepang (Magang, SSW, & Gijinkoku).

---

## 🚀 Fitur Utama

- **Desain Responsif & Modern**: Tampilan optimal di perangkat *mobile*, tablet, dan *desktop* menggunakan Tailwind CSS.
- **Scrollspy Navigation**: Indikator menu aktif yang berpindah otomatis sesuai posisi *scroll* pengguna.
- **Notifikasi Toast Interaktif**: Umpan balik kustom bergaya modern saat pengguna mengirimkan formulir pendaftaran.
- **Tombol Floating Back-to-Top**: Memudahkan navigasi kembali ke bagian atas halaman secara mulus.
- **Struktur Informasi Komprehensif**:
  - Profil & Sambutan Direktur
  - Transparansi Legalitas Perusahaan
  - Informasi Kemitraan Sending Organization (SO)
  - Kartu Komparasi Program Pelatihan (Magang, SSW, Gijinkoku)
  - Galeri Fasilitas & Formulir Pendaftaran Online

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman semantik & ramah SEO.
- **Tailwind CSS (v3)**: *Utility-first CSS framework* via CDN.
- **Custom CSS (`styles.css`)**: Animasi melayang (*floating animation*), *glassmorphism*, dan *custom scrollbar*.
- **JavaScript ES6 (`script.js`)**: Logika interaktif (*Scrollspy*, *Toast alert*, *Mobile toggle menu*, *Smooth scroll*).
- **Font Awesome (v6)**: Ikon visual pendukung UI.
- **Google Fonts**: Plus Jakarta Sans.

# Website LPKS Arima Persada (PT. Arima Bangkit Persada)

Situs web profil perusahaan (Company Profile) & pendaftaran online untuk **LPKS Arima Persada** — Lembaga Pelatihan Kerja Swasta persiapan program Magang (Ginou Jisshusei), Tokutei Ginou (SSW), dan Gijinkoku (Engineer) ke Jepang.

---

## 🌟 Fitur Utama
1. **Desain Modern & Responsif**: Tampilan bersih, elegan dengan perpaduan warna merah khas Jepang (`#D90429`) dan biru profesional (`#0A3155`), responsif di desktop, tablet, dan smartphone.
2. **Efek Interaktif Visual**:
   - Sticky Glassmorphism Header Navbar.
   - Smooth Scroll & Scroll-Reveal Animations (Intersection Observer).
   - Dynamic Counter Stat pada Hero Section.
   - Interactive Program Tabs (Magang, Tokutei Ginou, Gijinkoku).
   - Lightbox Gallery untuk dokumentasi fasilitas & asrama.
3. **Integrasi WhatsApp Direct Form**: Form pendaftaran siswa secara otomatis memformat teks dan meneruskan data pendaftar langsung ke WhatsApp Official (+62 812-8267-4707).
4. **Ringan & Bebas Dependensi Berat**: Dibangun menggunakan HTML5 murni, Modern CSS3, dan Vanilla JavaScript.
